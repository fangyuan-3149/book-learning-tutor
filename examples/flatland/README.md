# Example: a real generated course — *Flatland* (public domain)

This folder is **actual output** of the skill — not a mock-up. It shows what `teach.py`
produces from a real book, so you can judge the quality before installing anything.

- [`00_目录导读.md`](./00_目录导读.md) — the whole-book navigation the skill builds (chapter → lesson index + concept summary).
- [`第01章_I__Of_the_Nature_of_Flatland/第01课_I__Of_the_Nature_of_Flatland.md`](./第01章_I__Of_the_Nature_of_Flatland/第01课_I__Of_the_Nature_of_Flatland.md) — lesson 1, including its multimodal figure block.

*Flatland* (Edwin A. Abbott, 1884) is in the public domain, so it is safe to ship as a sample.
The teaching **session** shown in the main README's "▶ See it teach" block is the engine walking
through this exact lesson material.
