# 授业（Shouye）：书籍课程化 · 逐课教学闭环

> 2026-08-06 建立。把 PDF 教材变成「目录导读 + 章 + 课」的文件夹课程，让教师模型（deepseek）一课一课精准教学，token 零浪费。

## 项目一句话

**PDF 教材 → 课程文件夹 → 教师模型逐课教学闭环**，辅助人类 / AI 高效率学习：知道书籍构造、感知学习进度、一课一精华（去废话冗余）。

## 你要做什么（AI 角色）

1. 教材 PDF → 结构化 markdown（MinerU）
2. 识别章节 → 按规范生成课程文件夹 + 目录导读
3. 驱动教师模型逐课教学（lesson_builder + progress.json 闭环）

## 核心规范（必须遵守，用户定稿）

- 文件夹结构：

```
书库/
└── <书名>/
    ├── 00_目录导读.md            # 全书导航：章→课索引 + 知识点摘要
    ├── 第01章_<章名>/
    │   ├── 第01课_<课名>.md      # 教学单元（章节内最小粒度）
    │   └── ...
    └── progress.json             # 进度状态（按 章-课 记录已学/掌握度）
```

- **章节之后不再细化**：课 = 最小教学单元（文件内部可分知识点，不拆子文件夹）
- 命名带编号（`第01章_章名` / `第01课_课名`）→ 排序稳定、路径可预测
- 模型选课：一次只读「本课 + 目录导读 + 进度」三件，不碰全书其他内容

## 管道四阶段

```
① PDF → markdown    MinerU（版面分析/去页眉页脚/中文 OCR）
② 章节树            读 markdown 标题层级（#/##/###）→ 章/课边界
③ 生成结构          按规范建文件夹 + 每课写入内容 + 生成 00_目录导读.md
④ 逐课教学闭环      lesson_builder：本课 + 导读 + progress → 教学包（讲解精华+练习+小结）
                    → 标记掌握度 → 推进进度 → 下一课
```
